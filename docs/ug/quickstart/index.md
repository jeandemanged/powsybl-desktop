# Quick start tutorials

These tutorials take you from an empty application to load flow and security analysis results in a few minutes. They
use SmallGrid, a sample network bundled with the application, so you don't need any network file.

Follow them in order: the load flow and security analysis tutorials start from the network loaded in the first one.
