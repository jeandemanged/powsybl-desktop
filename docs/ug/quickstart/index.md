# Quick start tutorials

These tutorials take you from an empty application to load flow, security analysis and sensitivity analysis results
in a few minutes. They
use SmallGrid, a sample network bundled with the application, so you don't need any network file.

Follow them in order: the other tutorials start from the network loaded in the first one, and the sensitivity
analysis one uses the contingencies of the security analysis one.
