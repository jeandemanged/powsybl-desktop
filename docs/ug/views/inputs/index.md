# Inputs

The **Inputs** button of the main toolbar opens the per-network inputs of the computations: the contingencies of a
security or sensitivity analysis, the limit scalings applied to the operational limits, the factors of a sensitivity analysis, and the CRAC of a
remedial action optimization.
