# Line

The details of an AC line. Open it from the info button of the [Lines](../tables/lines.md) table, or from the other places listed in [Equipment details](index.md).

![The line view](../../../_generated/images/detail-line.png)

## Header

Links to the voltage levels of both sides, and the line symbol with the solved values and a connection check box at each end.

## Main tab

### Characteristics

| Field | Editor | Meaning |
|---|---|---|
| **R**, **X** | Text field | Series resistance and reactance (Ω). |
| **G1**, **B1** | Text field | Shunt conductance and susceptance at side 1 (S). |
| **G2**, **B2** | Text field | Shunt conductance and susceptance at side 2 (S). |

### Side 1, Side 2

The [Connection](index.md#connection-section) rows of each side.

## Other tabs

### Limits

The operational limits groups of each side. See [Edit operational limits](index.md#edit-operational-limits).

### Extensions

The extensions that can be added: Fortescue, Line Position, Connectable Position, Measurements, Operating Status, Observability, Dynamic Model.

### Properties and Aliases

See [Equipment details](index.md#edit-extensions-properties-and-aliases).
