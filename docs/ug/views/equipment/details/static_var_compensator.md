# Static Var Compensator

The details of a static var compensator. Open it from the info button of the [Static Var Compensators](../tables/static_var_compensators.md) table, or from the other places listed in [Equipment details](index.md).

![The static var compensator view](../../../_generated/images/detail-static-var-compensator.png)

## Header

A link to the voltage level, and the static var compensator symbol with the solved values and the connection check box.

## Main tab

### Connection

See [Connection](index.md#connection-section).

### Susceptance

| Field | Editor | Meaning |
|---|---|---|
| **B Min** | Text field | Minimum susceptance (S). |
| **B Max** | Text field | Maximum susceptance (S). |

### Local Targets

**Local Target V** and **Local Target Q**, see [Local Targets](index.md#local-targets-section).

### Voltage Regulation

See [Voltage Regulation](index.md#voltage-regulation-section). Modes **Voltage**, **Reactive Power** and **Voltage per Reactive Power**, local or remote.

## Other tabs

### Extensions

The extensions that can be added: Standby Automaton, Connectable Position, Reference Priorities, Observability, Measurements, Dynamic Model.
