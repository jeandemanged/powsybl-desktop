# Battery

The details of a battery. Open it from the info button of the [Batteries](../tables/batteries.md) table, or from the other places listed in [Equipment details](index.md).

![The battery view](../../../_generated/images/detail-battery.png)

## Header

A link to the voltage level, and the battery symbol with the solved values and the connection check box. On the right, the P/Q capability chart: the reactive limits, the target operating point and the solved one.

## Main tab

### Connection

See [Connection](index.md#connection-section).

### Active Power

| Field | Editor | Meaning |
|---|---|---|
| **Min P** | Text field | MW. |
| **Max P** | Text field | MW. |
| **Target P** | Text field | Active power target (MW). |

### Local Targets

**Local Target V** and **Local Target Q**, see [Local Targets](index.md#local-targets-section).

### Voltage Regulation

See [Voltage Regulation](index.md#voltage-regulation-section). Modes **Voltage** and **Reactive Power**.

## Other tabs

### Reactive Limits

The **Kind** of reactive limits, **Min/max** or **Capability curve**, and their values. See [Edit reactive limits](index.md#edit-reactive-limits).

### Extensions

The extensions that can be added: Active Power Control, Short Circuit, Manual Frequency Restoration Reserve, Connectable Position, Reference Priorities, Observability, Measurements, Dynamic Model.

### Properties and Aliases

See [Equipment details](index.md#edit-extensions-properties-and-aliases).
