# Substation

The details of a substation. Open it from the info button of the [Substations](../tables/substations.md) table, or from the other places listed in [Equipment details](index.md).

![The substation view](../../../_generated/images/detail-substation.png)

## Header

A link to the substation's single line diagram. No symbol.

## Main tab

### General

| Field | Editor | Meaning |
|---|---|---|
| **Country** | Searchable choice box | Empty for no country. |
| **TSO** | Text field | Transmission system operator. |
| **Geographical Tags** | Read-only | Added from the [Substations table](../tables/substations.md). |
| **Voltage Levels** | Link | One link per voltage level, to its [details](voltage_level.md). |

## Other tabs

### Extensions

The extensions that can be added: Substation Position, ENTSO-E Area, Dynamic Model.

### Properties and Aliases

See [Equipment details](index.md#edit-extensions-properties-and-aliases).
