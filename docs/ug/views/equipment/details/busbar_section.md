# Busbar Section

The details of a busbar section. Open it from the info button of the [Busbar Sections](../tables/busbar_sections.md) table, or from the other places listed in [Equipment details](index.md).

![The busbar section view](../../../_generated/images/detail-busbar-section.png)

## Header

A link to the voltage level, and the busbar symbol with its solved voltage and angle.

## Main tab

### Connection

See [Connection](index.md#connection-section).

## Other tabs

### Extensions

The extensions that can be added: Busbar Section Position, Operating Status, Connectable Position, Reference Priorities, Observability, Measurements, Dynamic Model.
