# Voltage Angle Limits

The **Voltage Angle Limits** table lists the voltage angle limits of the selected network: bounds on the voltage angle difference between two terminals. Open it with **Tables** > **Equipment** > **Voltage Angle Limits**.

![The Voltage Angle Limits table of the EurostagTutorialExample1Factory createWithVoltageAngleLimit sample network](../../../_generated/images/table-voltage-angle-limits.png)

## Columns

| Column | Group | Editable | Meaning |
|---|---|---|---|
| **Id** |  |  | The id, after a copy button. |
| **From terminal** |  |  | Equipment of the first terminal, with its side for a multi-sided one. |
| **To terminal** |  |  | Equipment of the second terminal. |
| **Low limit** |  |  | °. |
| **High limit** |  |  | °. |

The table is read-only, has no search box, no detail view and no right-click menu.

## Creation and removal

The **New** button of the table toolbar opens the dialog creating a voltage angle limit; **Remove** removes the selected one.
