# Grounds

The **Grounds** table lists the grounds of the selected network. Open it with **Tables** > **Equipment** > **Grounds**. It is also a tab of the [Substations](../../diagrams/substations.md) view, for the selected substation or voltage level.

![The Grounds table of the TwoVoltageLevelNetworkFactory createWithGrounds sample network](../../../_generated/images/table-grounds.png)

## Columns

**Substation**, **Voltage Level**, **Name**, **Connected** and **CC** are the [common columns](index.md#rows-and-columns).

The table has no other column.

## Creation and removal

**New** > **Ground…** creates a ground, in the selected row's voltage level by default. The **Remove** button removes the selected row's ground, after a confirmation listing what is removed with it.

## Details

The info button of the **Name** column opens the [ground details](../details/ground.md).
